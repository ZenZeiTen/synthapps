# Lintas promo video

A 90-second, 1920×1080, 30 fps promotional video for [Lintas](../lintas), built with
[Remotion](https://www.remotion.dev) (React) and Three.js, from real Lintas screenshots.

| Scene | Length | File |
|---|---|---|
| Intro: logo and "The browser built for translators." | 7 s | `src/scenes/S1Intro.tsx` |
| Hook: "Browse. Translate. Ship." | 4 s | `S2Hook.tsx` |
| Fast, private, works offline | 12 s | `S3Browse.tsx` |
| Translate pages in place | 12 s | `S4Translate.tsx` |
| The built-in TMS | 15 s | `S5Tms.tsx` |
| AI Oracle with the 3D Jade Wisp | 15 s | `S6Oracle.tsx` |
| Extensions, Claude in Chrome, Claude Desktop | 12 s | `S7Ext.tsx` |
| Secure by design | 8 s | `S8Secure.tsx` |
| Outro: logo, "Free for Windows · Version 0.5.1", "A Nusalexia product" | 9 s | `S9Outro.tsx` |

Eight 0.5-second transitions overlap the scenes, so the total is exactly 90 s.

## Assets

- `public/shots/`: screenshots of Lintas itself.
- `public/music.m4a`: original music, generated by `scripts/make-music.py` (numpy, no samples).
  To regenerate it:
  `python3 scripts/make-music.py music.wav && ffmpeg -i music.wav -c:a aac -b:a 160k public/music.m4a`.
- `public/sfx/`: Remotion's free sound effects (https://remotion.media).

## Preview and render

```bash
npm i
```

```bash
npx remotion studio
```

```bash
npx remotion render LintasPromo out/lintas-promo.mp4 --codec=h264 --crf=20
```

In a headless Linux container, add `--gl=swangle`, or the 3D scene renders black.
The render took about 11 minutes there.

Remotion is free for teams of up to 3 people; larger companies need a licence
(https://www.remotion.dev/docs/license).
