A fast, elegant block theme for any business, with six style variations, ready-made pages and light and dark mode.

== Description ==

Corbelwise is a block theme for businesses of every kind: consultants, clinics, restaurants, studios, shops and agencies. Everything is edited visually in the Site Editor.

* Six style variations: Ink (default), Ocean, Sage, Ember, Noir and Mono. Each sets light and dark colours and fonts.
* More than twenty sections (hero, services, numbers, steps, testimonials, pricing, questions, team, contact, calls to action, latest posts) and five full pages (home, about, services, pricing, contact).
* Light and dark mode that follows the visitor's device, with an optional switch in the header.
* Fast: no jQuery, about 1 KB of JavaScript, self-hosted variable fonts with preloading, and core block styles loaded only where blocks are used.
* Templates for posts, pages, archives, search, 404, a page without title, a wide page, a landing page and a blank canvas.
* Appearance → Corbelwise: a getting-started page, dark mode and sticky header options, and a one-click home page.

The optional Corbelwise Toolkit plugin adds performance and security settings, SEO and structured data, business details, an announcement bar and an AI assistant.

== Installation ==

1. In WordPress, go to Appearance → Themes → Add New Theme → Upload Theme.
2. Choose corbelwise.zip and click Install Now, then Activate.
3. Open Appearance → Corbelwise and follow the steps.

== Frequently Asked Questions ==

= Why is my front page a list of posts? =

Open Appearance → Corbelwise and click "Create my pages", or set a page as your front page under Settings → Reading.

= Does the theme update itself? =

No. Download new versions from your purchase and upload them under Appearance → Themes → Add New Theme → Upload Theme, choosing "Replace active with uploaded". The theme blocks WordPress.org update offers for its folder name, because such an offer would be a different theme.
