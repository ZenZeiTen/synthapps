A WordPress block theme for any business, with a companion plugin of switchable modules and an optional AI assistant powered by Claude.

## Install

Download the two zips below (or the package, which contains both plus the user guide).

1. **Theme:** Appearance → Themes → Add New Theme → Upload Theme, choose `corbelwise-1.0.0.zip`, Install Now, Activate.
2. **Plugin (recommended):** Plugins → Add New Plugin → Upload Plugin, choose `corbelwise-toolkit-1.0.0.zip`, Install Now, Activate.
3. Open **Appearance → Corbelwise** and click **Create my pages** to get a finished Home, About, Services, Pricing and Contact page.

Needs WordPress 6.5 or newer and PHP 7.4 or newer.

## What's in 1.0.0

**Theme**
- Six style variations (Ink, Ocean, Sage, Ember, Noir, Mono), each with light and dark colours that meet WCAG AA contrast.
- 21 ready-made sections and 5 full-page layouts; 11 templates including a landing page and a blank canvas.
- Light and dark mode that follows the visitor's device, with an optional switch in the header.
- No jQuery, self-hosted fonts, about 1.4 KB of JavaScript.

**Corbelwise Toolkit**
- Performance, Security, SEO and sharing, Business details, Announcement bar and AI assistant modules, each switched on or off under the Corbelwise menu.
- AI assistant (off by default, uses your own Anthropic API key): a writing assistant in the editor and an optional visitor chat that answers from your own pages, with per-visitor and daily limits to keep costs predictable.

## Updating later

Upload the new zip the same way and choose **Replace active with uploaded** (theme) or **Replace current with uploaded** (plugin). Pages, styles and settings are kept. WordPress never offers Corbelwise updates on its own; if it shows a "new version" for either folder, it is a different product, so do not accept it.
