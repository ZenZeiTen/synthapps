# reality.js plugin

A Claude Code skill for [reality.js](../../README.md), the scene language
and path tracer in this folder. With it, Claude writes `.real` scenes the
way a photographer sets up a shot, checks them without a GPU, renders
drafts before finals, and budgets render time.

```
/plugin marketplace add ZenZeiTen/synthapps
/plugin install reality-js@synthapps
```

The skill works on a checkout of this repository (it uses `reality-js/src`
and `tools/render.mjs`). It contains:

- `skills/reality-js/SKILL.md`: the workflow, the look (light, lens,
  exposure, film, materials), motion, speed budgeting and troubleshooting.
- `skills/reality-js/scripts/check.mjs`: compiles a scene in Node, reports
  errors and warnings, lists shader features, and estimates render time.
- `skills/reality-js/templates/`: seven tested starting scenes.
- `skills/reality-js/references/`: a generated property cheat sheet, the
  JavaScript API, and rules for extending the renderer.

`references/cheatsheet.md` is generated by `node tools/gen-cheatsheet.mjs`;
`npm test` fails if it drifts from the language.
